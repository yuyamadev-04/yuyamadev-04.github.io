プライバシーポリシー

本方針は、YouTubeチャンネル「サッカー民の反応集」の管理者が運用する個人用ツール YouTube Auto Maker と、その説明サイトに適用します。本ツールは管理者自身のチャンネル運用に使用し、一般の利用者からGoogleアカウントへの接続を募集しません。

1. アクセス・保存する情報

  • Googleが発行するアクセストークン、リフレッシュトークン、および許可されたアクセス範囲。
  • 接続したYouTubeチャンネルのID、名称、登録者数など、投稿先を照合するための情報。
  • 管理対象の動画ID、タイトル、説明文、サムネイル、公開状態、投稿日時、処理状況、投稿記録。
  • 分析用の許可がある場合、視聴回数、再生時間、視聴維持や流入、インプレッション等のうち、APIから取得可能で運用に必要な集計値。
  • 運用者が投稿対象として指定した動画、画像、タイトル、説明文などの制作物。

2. 使用目的

投稿先の確認、明示された動画のアップロードとサムネイル設定、重複投稿の防止、投稿結果の確認、およびチャンネル実績の分析に使用します。データを販売したり、広告配信や信用評価のために使用したりしません。

3. 保存と外部への送信

認証情報は運用者のWindows PCでWindows DPAPIによって暗号化します。チャンネル情報、投稿記録、分析結果は運用者のPCに保存します。完成動画と投稿用の説明文などは、運用者の指定により本人のiCloud Driveへコピーする場合があります。Googleの認証トークンはiCloudやこの公開サイトへコピーしません。

認証とAPI処理のためにGoogleへ接続し、投稿時には指定された動画・画像・メタデータをYouTubeへ送信します。運用者はAIによる作業支援を利用しており、作業に必要なタイトル、投稿状態、集計された分析結果などが支援サービスに表示される場合があります。認証トークンやパスワードは、その会話、公開サイト、公開リポジトリへ記載しません。

本ツールは取得したGoogleユーザーデータを汎用のAI・機械学習モデルの開発や学習のために使用しません。Google APIから取得した情報の利用・他アプリへの転送は、Google API Services User Data Policy（Limited Use要件を含む）に従うものとします。

4. 保存期間と削除

認証情報は利用を継続する間保存し、接続を廃止した際はPC上の保存情報を削除します。投稿記録は重複投稿の防止や運用履歴のため、運用上必要な期間保存します。分析結果は取得日時を付して保管し、現在の数値として使う場合は再取得します。

チャンネル管理者は自分のPC上の保存データとiCloud上のコピーを削除できます。保存データの削除と、YouTubeへアップロード済みの動画の削除は別の操作です。YouTube上の動画はYouTube Studioで管理できます。Googleで許可を取り消しただけでは、PCに保存済みのファイルは自動削除されません。

5. Googleのアクセス許可を取り消す方法

Googleアカウントの接続管理画面から、本ツールへのアクセスを取り消せます。取り消し後は、新たに許可するまで投稿・分析のAPI操作を行えません。

6. この説明サイト

このサイトにGoogleログイン機能、個人情報の入力フォーム、広告、運用者が設置したアクセス解析スクリプトはありません。ホスティング先のGitHubはセキュリティ等のためアクセス時のIPアドレス等を処理します。詳細はGitHubのプライバシーステートメントをご覧ください。

7. お問い合わせと変更

運用者はサッカー民の反応集のチャンネル管理者です。方針へのお問い合わせは公開の問い合わせ窓口へお寄せください。個人情報や認証情報は書き込まないでください。取り扱いに変更がある場合は、このページを更新します。
